Tactiques clés

  • Faux freemium (teaser pur) : extraits seulement, jamais d'unité de valeur complète gratuite. Hard paywall masqué.
  • Paywall offert très tôt (écran 9, avant tout contenu) : pari sur la conversion par projection (200+ heures, 10k notes, prix barré -50%).
  • Personnalisation amont avec sunk cost léger : profil + âge + langue + 2 quiz d'intention (objectifs sommeil/relax/apprentissage, types d'histoires).
  • Compte différé post-skip paywall : l'user qui refuse de payer est cadré dans un ask plus léger (email pour bénéfices fonctionnels).
  • Bandeau « Débloquer Premium » persistant sur toutes les fiches : re-pitch permanent.
  • Contrôle parental arithmétique (six fois six) requis même pour aller payer, + mode nuit dédié, + écran d'écoute immersif sombre (anti-temps d'écran radical).
  • Auth email/password seule : pas de SSO Apple/Google, pas de magic link. Friction inhabituelle pour 2026.

L'avis

Force
  • Positionnement wellness anti-temps d'écran clair dès le splash.
  • Identité visuelle moderne et épurée.
  • Contrôle parental riche + écran d'écoute immersif sombre.
Risques
  • Que des extraits : sensation de fausse promesse, churn post-trial probable.
  • Auth sans SSO ni magic link : friction sign-up.
  • Paywall trop tôt + trust minimal sans cautions externes.
Position marché
  • Contrarian : angle wellness anti-temps d'écran sans équivalent FR direct.
  • Standard sur reverse trial CB.
  • Sévère sur la dose de gratuit (nulle).

Impact / reproductibilité pour Kidsono

À reproduire
  • Positionnement anti-temps d'écran + identité moderne épurée.
  • Écran d'écoute immersif sombre + mode nuit dédié.
  • Contrôle parental fort + compte différé post-skip paywall.
À éviter
  • Faux freemium (donner au moins une histoire complète gratuite par profil).
  • Auth sans SSO/magic link.
  • Paywall trop tôt + trust minimal (Kidsono doit activer Gallimard / École des Loisirs / Nathan).
À tester
  • Contrôle parental conditionnant le paiement (cohérent mais friction).
  • Combiner trust « produit moderne » + trust éditorial (ni Bayam ni Alma).

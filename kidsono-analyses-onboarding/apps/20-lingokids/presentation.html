Tactiques & éléments de réassurance
  • Double voie perso/direct (06) : laisse le parent doser son effort, défaut sur l'accès direct (anti-drop-off). Nouveauté du corpus.
  • Reverse trial skippable (08) : maximise les essais sans bloquer l'accès au freemium.
  • Asymétrie de l'essai (15) : offert puis retiré → pression de conversion croissante sur le user déjà engagé.
  • Caution académique Oxford répétée (03, 18) : cohérente avec la promesse éducative (playlearning).
  • Cadenas + "Essayez Plus" persistant (11, 17) : frustration ciblée sur les licences désirées (Zootopia, Mickey, Spider-Man).
  • Pas de dark pattern dur : paywall et compte clairement skippables (croix), freemium réel.

L'avis

Force
  • Double voie perso/direct (défaut malin sur le direct).
  • Freemium réel : activités complètes gratuites.
  • Caution Oxford cohérente avec la promesse éducative.
Risques
  • Asymétrie de l'essai : sensation d'inéquité possible.
  • Prix élevé (14,99 €/mois) vs le freemium gratuit.
  • Trust diffus : aucun signal massif sauf Oxford.
Position marché
  • En avance sur la double voie explicite.
  • Standard sur le reverse trial skippable + freemium.
  • Discutable sur l'asymétrie de l'essai.

Impact / reproductibilité pour Kidsono

À reproduire
  • Double voie "perso vs accès direct", défaut sur le direct.
  • Freemium avec vraies activités complètes gratuites.
  • Caution éditoriale / culturelle forte (Gallimard, Opéra de Paris = l'Oxford de Kidsono).
À éviter
  • Asymétrie de l'essai (offert puis retiré) : risque de churn / sentiment de piège.
À tester
  • Default "accès direct" vs default "perso" (activation, rétention).
  • Essai 7 j à l'onboarding + freemium sans CB en parallèle (volume vs conversion).
